Delivery Route Optimization

Travelling Salesperson Problem (TSP)

Find the shortest delivery route starting from the warehouse, visiting all customers and returning to the warehouse.

1. Problem Statement

The Delivery Route Optimization problem is based on the Travelling Salesperson Problem (TSP). A delivery person must visit every customer exactly once and return to the warehouse. The objective is to minimize the total distance.

Why does it matter in real life?

  • Reduces fuel consumption.
  • Saves delivery time.
  • Reduces transportation costs.
  • Improves courier and logistics services.
  • Helps plan efficient delivery routes.

What does the program compute?

The program calculates the delivery route and total distance using four algorithms: Brute Force, Dynamic Programming, Greedy and Dijkstra-based routing.

4. Step-by-Step Working

Brute Force

  1. Start from the warehouse.
  2. Generate all possible customer orders.
  3. Calculate each route distance.
  4. Return to the warehouse.
  5. Select the route with minimum distance.

Dynamic Programming

  1. Start from the warehouse.
  2. Represent visited customers using bitmasks.
  3. Calculate costs for remaining customers.
  4. Store calculated states using memoization.
  5. Reconstruct the optimal route.

Greedy

  1. Start from the warehouse.
  2. Find the nearest unvisited customer.
  3. Visit that customer.
  4. Repeat until all customers are visited.
  5. Return to the warehouse.

Dijkstra

  1. Initialize source distance as zero.
  2. Set all other distances to infinity.
  3. Select the unvisited vertex with minimum distance.
  4. Update neighbouring distances.
  5. Repeat to find shortest paths.
  6. Use these paths to construct a delivery tour.

5. Required Algorithm Syntax

Brute Force – Recursion

GENERATE(remaining, route):

    IF remaining is empty:
        calculate total distance
        update minimum route
        RETURN

    FOR each customer:
        remove customer from remaining
        GENERATE(remaining, route + customer)

Dynamic Programming – Memoization

TSP(mask, current):

    IF all customers visited:
        RETURN distance[current][0]

    IF state exists in memo:
        RETURN memo[state]

    best = INFINITY

    FOR each unvisited customer:
        calculate candidate cost
        best = MIN(best, candidate)

    memo[state] = best
    RETURN best

Greedy – Nearest Neighbour

current = warehouse

WHILE unvisited customers remain:

    nearest = minimum distance customer

    visit nearest

    mark nearest as visited

    current = nearest

RETURN to warehouse

Dijkstra – Relaxation

dist[source] = 0

All other distances = INFINITY

WHILE unvisited vertices remain:

    u = minimum distance vertex

    mark u as visited

    FOR each neighbour v:

        IF dist[u] + weight[u][v] < dist[v]:

            dist[v] = dist[u] + weight[u][v]

            previous[v] = u
